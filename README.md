# tilda-site

Внешний код (CSS/JS) для сайта на Тильде. Хостинг — GitHub Pages.

## Подключение (один раз, на весь сайт)

Тильда → Настройки сайта → Вставка кода (или «Ещё») → «HTML-код для вставки внутрь HEAD»:

```html
<script src="https://katrinstrizh.github.io/tilda-site/loader.js"></script>
```

Сохранить → «Опубликовать все страницы». Дальше правки делаются только здесь, без Тильды.

## Структура

- `loader.js` — загрузчик: общий код + код страницы по её адресу (карта `PAGES`).
- `css/common.css`, `js/common.js` — код для всех страниц.
- `pages/<имя>.css|js` — код отдельной страницы (зарегистрировать в `PAGES`).

Обновление на сайте — до ~10 минут (кэш GitHub Pages). Для сброса кэша браузера увеличить `V` в loader.js.
Проверка: на опубликованной странице `document.documentElement.dataset.customCode === 'ok'`.
